# Internacionalización de UniTutor

La aplicación usa español (`es`) por defecto e inglés (`en`) como segundo idioma.
La primera visita muestra español, independientemente del idioma del navegador.
El selector está en las pantallas públicas y en la cabecera de las pantallas privadas.
La preferencia se guarda en `localStorage` con la clave `unitutor_language`.
Si el almacenamiento está bloqueado, el selector sigue funcionando durante la sesión.
El atributo `lang` del documento y las fechas cambian con el idioma seleccionado.

## Piezas

| Archivo | Responsabilidad |
| --- | --- |
| `src/i18n/Lang/es.json` | Textos en español y claves de referencia |
| `src/i18n/Lang/en.json` | Los mismos textos en inglés |
| `src/i18n/core.ts` | Traducción, fallback al español e interpolación |
| `src/i18n/store.ts` | Estado compartido con Zustand y persistencia local |
| `src/i18n/useTranslations.ts` | Hook de React con `t`, `language`, `setLanguage` y `locale` |
| `src/shared/components/LanguageSelector.tsx` | Selector accesible de idioma |
| `scripts/check-i18n.mjs` | Verifica claves y detecta texto JSX y atributos sin traducir |

Se usan las dependencias existentes. La implementación no necesita Laravel ni un backend de traducciones.
El hook mantiene las pantallas sincronizadas con el estado de idioma de React.
Referencia de React: https://react.dev/reference/react/useSyncExternalStore

## Agregar un texto

1. Agrega la misma clave a ambos JSON. La clave es el texto original en español.
2. En el componente, usa el hook y traduce el texto:

```tsx
import { useTranslations } from '@/i18n/useTranslations'

export function Example() {
  const { t } = useTranslations()
  return <button>{t('Guardar Cambios')}</button>
}
```

Para texto dinámico usa parámetros, conservando los mismos nombres en ambos idiomas:

```tsx
t('¡Bienvenido, {name}!', { name: 'Ana' })
```

Para fechas:

```tsx
const { locale } = useTranslations()
new Date(createdAt).toLocaleDateString(locale)
```

Incluye `t` en las dependencias de un `useMemo` o `useCallback` que genere traducciones,
para que sus resultados se actualicen al cambiar el idioma.

## Verificación

```sh
npm test
npm run lint:i18n
npm run lint
npm run build
```

Las pruebas cubren el idioma predeterminado, diccionarios equivalentes, parámetros,
persistencia, actualización de `html.lang` y almacenamiento bloqueado.
El detector cubre texto JSX y atributos literales (`label`, `placeholder`, `title`,
`aria-label`); no reemplaza la revisión de mensajes construidos dinámicamente.

Los nombres y descripciones guardados en Supabase se muestran tal como fueron registrados.
Los errores externos del backend se conservan cuando no existe una traducción conocida.
La preferencia es local al navegador y no se sincroniza entre dispositivos.
